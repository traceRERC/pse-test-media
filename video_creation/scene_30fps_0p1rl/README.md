# Scene changes at 30 fps with 0.1 relative luminance threshold

 - **File:** scene_30fps_0p1rl.csv
 - **Standard:** none
 - **Flash type:** Luminance scene changes
 - **Frame rate:** 30 fps
 - **Dynamic range:** SDR
 - **Color space:** sRGB
 - **Number of videos:** 12

**Description:** These videos were created to test an experimental scene change hazard:

 - $\ge$80% screen area
 - $\gt$3 alternating transitions in any 1 second period
 - $\ge$0.1 relative luminance difference

Failing videos exceed all of these thresholds by a small amount.
Passing videos only have one dimension that passes at a time with other dimensions exceeding thresholds by a small amount.
